# Kharkiv Air Map

Гражданская карта воздушных угроз для Харькова и Харьковской области.

Проект агрегирует **только открытые и официальные источники**, нормализует сообщения и показывает их на одной веб-карте. Он не использует закрытые военные данные и не пытается дорисовывать точные траектории там, где их нет в источнике.

## Источники

По умолчанию подключены публичные Telegram-источники:

- `@radar_kharkov` — RADAR KH
- `@tlknewsua` — TLK News
- `@monitor1654` — monitor 1654 | Харків
- `@radar_harkiv` — Харків Alerts
- `@kpszsu` — Повітряні Сили ЗС України
- `@war_monitor` — monitor
- `@kharkivlife` — Харьков life | Харків

Также поддерживается официальный API `alerts.in.ua` при наличии `ALERTS_API_TOKEN`.

`ЄППО` не подключается автоматически, потому что публичный API для чтения событий не заявлен. Система готова к добавлению официального адаптера, если такой интерфейс станет доступен.

## Что показывает карта

- тип угрозы: FPV, Молнія, Shahed/БПЛА, ракета, КАБ, баллистика, РСЗВ;
- опубликованную точку/район;
- направление, только если оно явно написано в исходном сообщении;
- источник и ссылку на сообщение;
- время публикации;
- возраст события;
- количество сообщений по одной зоне.

## Быстрый запуск

```bash
cp .env.example .env
docker compose up --build
```

Открыть: `http://localhost:8000`

Без Docker:

```bash
python -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:app --host 0.0.0.0 --port 8000
```

## Переменные окружения

```env
POLL_SECONDS=20
EVENT_TTL_MINUTES=20
ALERTS_API_TOKEN=
```

`ALERTS_API_TOKEN` нужен только для официального слоя alerts.in.ua. Токен нельзя помещать во frontend.

## Развёртывание

В репозитории есть `Dockerfile`, `docker-compose.yml` и `render.yaml`. Проект можно развернуть на Render/Railway/Fly.io или любом VPS с Docker.

Для публичного использования рекомендуется поставить Cloudflare перед приложением и ограничить частоту запросов к backend.

## Важное ограничение

Это вспомогательный гражданский инструмент. Он зависит от доступности и задержек сторонних источников и не заменяет официальные сигналы воздушной тревоги, сообщения ДСНС/ОВА и укрытие.
